## 출처 사용 규칙

1. 코드나 수식을 작성할 때 사용한 출처를 해당 함수 또는 단계 문서에 연결한다.
2. 직접 단순화한 부분은 “직접 작성/교육용 단순화”라고 명시한다.
3. 특정 제품의 기본 파라미터를 그대로 복사하지 않는다.
4. 실험 파라미터는 프로젝트 가정과 측정 결과를 근거로 정한다.
5. 회사 자료나 출처를 확인할 수 없는 설계 내용은 사용하지 않는다.
