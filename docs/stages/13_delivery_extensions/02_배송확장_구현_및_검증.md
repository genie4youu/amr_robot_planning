# 배송 확장 구현 및 검증

## 구현 순서

1. order와 payload data contract를 만든다.
2. loading/unloading delay를 Stateflow에 추가한다.
3. 단순 battery energy model을 plant에 추가한다.
4. low/critical SOC와 hysteresis를 추가한다.
5. mission acceptance를 거리 기반으로 구현한다.
6. charger와 pre-dock pose를 map에 정의한다.
7. fine docking controller를 별도로 만든다.
8. docking timeout/retry를 Stateflow에 추가한다.
9. 충전과 mission resume 정책을 검증한다.

## 예정 파일

```text
src/+amr/+modeling/updateBatteryEnergy.m
src/+amr/+control/fineDockingCommand.m
src/+amr/+verification/evaluateDeliveryMission.m
data/scenarios/low_battery_delivery.mat
tests/scenarios/verify_low_battery_return.m
tests/scenarios/verify_docking_recovery.m
```

## 검증 시나리오

- 충분한 SOC의 정상 배송
- 시작 전 SOC 부족
- 배송 중 예상보다 큰 소비
- pre-dock 도착
- docking pose 오차
- docking sensor dropout
- 충전 완료 후 대기
