# 배송 임무, 배터리, 도킹 이론

## 배송 상태

최소 데이터:

- order ID
- pickup pose
- dropoff pose
- payload state
- priority
- mission status

payload state 후보:

```text
Empty → Loading → Loaded → Unloading → Empty
```

## 배터리

첫 모델은 energy accounting으로 시작한다.

- idle power
- motion power
- acceleration 또는 wheel effort 영향
- sensor/controller base load
- charging power
- SOC saturation

단순 Coulomb counting 또는 energy integration을 사용할 수 있지만, 모델의 가정과 단위를 명시한다.

## 임무 가능성 판단

현재 위치에서 pickup, dropoff, charger까지의 예상 경로 비용과 안전 reserve를 비교한다. 첫 버전은 보수적인 거리 기반 추정으로 시작한다.

## 도킹

두 단계로 분리한다.

1. global navigation으로 pre-dock pose 도착
2. 상대 pose 기반 저속 정렬과 접근

고급 카메라나 marker 없이 ideal dock-relative pose를 가상 측정으로 제공하고, noise와 dropout은 이후 추가한다.

## Stateflow 확장

- `AssessMission`
- `ReturnToCharger`
- `PreDock`
- `FineDocking`
- `Charging`
- `DockRecovery`
