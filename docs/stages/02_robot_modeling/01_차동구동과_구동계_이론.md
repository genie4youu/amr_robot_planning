# 차동구동과 구동계 이론

## 운동학

바퀴 반지름 `r`, 좌우 바퀴 각속도 `omegaL`, `omegaR`, track width `L`에 대해:

\[
v = \frac{r}{2}(\omega_R + \omega_L)
\]

\[
\omega = \frac{r}{L}(\omega_R - \omega_L)
\]

\[
\dot{x}=v\cos\theta,\quad
\dot{y}=v\sin\theta,\quad
\dot{\theta}=\omega
\]

## 역운동학

원하는 `v`, `omega`에서 좌우 바퀴 속도를 구한다. 유도 과정과 부호를 문서에 직접 적고 단위 검사를 수행한다.

## 구동계 단순화

초기 plant에는 다음만 포함한다.

- 모터 속도 1차 지연
- 바퀴 속도 포화
- 가속도 제한
- dead zone

고급 항목은 단계적으로 추가한다.

- 좌우 바퀴 반경 차이
- track-width 오차
- 속도에 따른 slip
- 하중과 배터리에 따른 응답 변화

## 수치 적분

- 초기에는 Euler 적분으로 수식 확인
- 이후 midpoint 또는 exact arc integration과 비교
- 작은 각속도에서 수치적으로 안정적인 분기 필요
