# 로봇 플랜트 구현 및 검증

## 구현 순서

1. forward kinematics MATLAB 함수를 작성한다.
2. inverse kinematics를 작성한다.
3. 한 sample의 pose integration을 작성한다.
4. 직진, 회전, 원운동 수치 예제를 만든다.
5. 모터 1차 지연, 포화, dead zone을 추가한다.
6. 바퀴 속도 PI controller를 분리한다.
7. prototype Simulink model로 이식한다.
8. command와 ground truth를 logging한다.

## 예정 파일

```text
src/+amr/+modeling/differentialDriveForward.m
src/+amr/+modeling/differentialDriveInverse.m
src/+amr/+modeling/integrateDifferentialDrive.m
src/+amr/+modeling/applyMotorDynamics.m
src/+amr/+control/wheelSpeedPI.m
tests/unit/verify_differential_drive.m
models/prototypes/amr_diff_drive_prototype.slx
```

## 시나리오

- 좌우 바퀴 동일 속도
- 좌우 바퀴 반대 속도
- 한쪽 바퀴 정지
- 포화보다 큰 명령
- dead zone보다 작은 명령
- 정방향에서 역방향으로 전환

## 통과 기준

- 이상적인 조건에서 해석 결과와 수치 결과가 일치한다.
- 제한 조건을 넘는 내부 상태가 없다.
- solver와 step size 변경 영향이 설명되어 있다.
