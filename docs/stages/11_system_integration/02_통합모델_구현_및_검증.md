# 통합 모델 구현 및 검증

## 통합 순서

1. plant + ideal sensor + ground-truth pose + Pure Pursuit
2. global costmap + A*
3. local costmap + DWA
4. safety gate
5. Stateflow normal mission
6. odometry/localization pose source
7. failure feedback와 recovery
8. mapping mode
9. SLAM 결과의 offline map 사용
10. 배터리·도킹 확장 전 baseline 고정

한 번에 두 개 이상의 큰 subsystem을 추가하지 않는다.

## 예정 파일

```text
models/integrated_system/amr_integrated_delivery_system.slx
scripts/setup_amr_project.m
scripts/create_default_amr_params.m
scripts/run_amr_scenario.m
scripts/plot_amr_run.m
data/scenarios/normal_delivery.mat
```

## 통합 smoke test

- model update 성공
- unconnected port 없음
- data type/size 불일치 없음
- 시작 직후 invalid 데이터로 이동하지 않음
- zero command에서 plant가 정지
- emergency에서 최종 command가 zero
- logging 변수와 시간축이 존재

## 단계별 회귀

새 subsystem을 연결할 때 이전 단계의 정상 시나리오를 다시 실행한다. 실패하면 통합을 진행하지 않고 마지막으로 추가한 경계부터 확인한다.

## 모델 점검 절차

```text
load_system
→ model_read
→ 작은 model_edit
→ model_read
→ model_check
→ sim
→ MATLAB assert
→ 실험 기록
```

`model_test`는 사용하지 않는다.
