# 세팅 및 검증 절차

## 구현 순서

1. `ver` 결과에서 MATLAB, Simulink, Stateflow 버전을 기록한다.
2. 프로젝트 루트를 기준으로 MATLAB 경로에 추가할 폴더를 결정한다.
3. `artifacts/cache`, `artifacts/codegen`, `artifacts/logs`의 위치를 결정한다.
4. 로봇 공통 파라미터 구조의 이름과 필드를 설계한다.
5. pose, velocity command, laser scan, health status의 schema 초안을 만든다.
6. SI 단위와 좌표축 규칙을 예제 값으로 확인한다.
7. 단계 완료 템플릿을 복사해 첫 결과 기록을 작성한다.

## 예정 파일

```text
scripts/setup_amr_project.m
scripts/create_default_amr_params.m
src/+amr/+common/validatePose.m
tests/unit/verify_project_setup.m
```

실제 파일은 다음 세션에서 하나씩 만들며, 현재 문서 단계에서는 이름과 책임만 확정한다.

## 첫 검증 항목

- 프로젝트 루트 밖의 경로를 추가하지 않는다.
- 파라미터의 모든 물리량에 단위 설명이 있다.
- pose는 `[x, y, theta]` 순서를 사용한다.
- velocity command는 `[v, omega]` 순서를 사용한다.
- 잘못된 배열 크기나 `NaN`을 invalid로 판정하는 규칙이 있다.
