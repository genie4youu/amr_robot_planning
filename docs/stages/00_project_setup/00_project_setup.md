# 00. Project Setup

## 목적

환경 제약, 단위, 좌표계 이름, 데이터 계약, 생성물 위치와 기록 방식을 고정한다. 이후 모든 단계가 이 기준을 사용한다.

## 진입 조건

- MATLAB R2025b, Simulink, Stateflow를 실행할 수 있다.
- 현재 프로젝트가 ROS 및 Robotics 관련 Toolbox에 의존하지 않는다는 데 합의했다.

## 결과물

- 환경 baseline
- SI 단위와 좌표축 규칙
- 공통 파라미터 이름
- 주요 데이터의 schema 초안
- 생성 artifact 저장 규칙
- 단계별 실행 및 기록 방법

## 완료 조건

- [ ] 사용 가능한 MATLAB 제품을 기록했다.
- [ ] 금지된 의존성과 기존 모델 보호 규칙을 기록했다.
- [ ] `x`, `y`, `theta`, `v`, `omega`의 단위와 부호를 확정했다.
- [ ] 주요 데이터 계약에 timestamp와 valid 항목을 포함했다.
- [ ] 첫 번째 MATLAB 수치 검증을 어디서 실행하고 기록할지 확정했다.
