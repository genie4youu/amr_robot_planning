# 환경과 프로젝트 규칙

## 현재 기준 환경

- 운영체제: Windows 11
- MATLAB: R2025b Update 5
- 사용 제품: MATLAB, Simulink, Stateflow
- 사용하지 않는 제품: ROS Toolbox, Robotics System Toolbox, Simulink Test
- MATLAB 연결: 실행 중인 세션에서 `satk`

## 공통 단위

| 값 | 단위 |
| --- | --- |
| 위치와 거리 | m |
| 각도 | rad |
| 선속도 | m/s |
| 각속도 | rad/s |
| 시간 | s |
| 바퀴 회전속도 | rad/s |

## 좌표축 초안

- world/map frame: `+x` 오른쪽, `+y` 위쪽, `+theta` 반시계 방향
- robot/base frame: `+x` 전방, `+y` 좌측
- 각도는 내부 계산에서 radian을 사용하고 필요할 때만 표시를 degree로 바꾼다.

## 데이터 계약 최소 항목

모든 데이터에 모두 필요한 것은 아니지만 다음 필드를 기준으로 검토한다.

```text
value
timestamp
valid
frame
covariance
sequence
```

## 재현성 규칙

- random seed를 기록한다.
- 초기 조건과 파라미터를 실행 스크립트에서 명시한다.
- Base Workspace의 남은 값에 우연히 의존하지 않는다.
- 결과를 만든 코드와 모델을 함께 연결한다.
- 실패한 실행도 삭제하지 않고 기록한다.

## 파일 보호

- 공개 출처 또는 이 저장소에서 직접 만든 예제만 사용한다.
- 개인·회사 자료와 출처를 확인할 수 없는 설계 내용을 저장소에 포함하지 않는다.
- 공개 출처 또는 직접 작성한 교육용 설계만 사용한다.
