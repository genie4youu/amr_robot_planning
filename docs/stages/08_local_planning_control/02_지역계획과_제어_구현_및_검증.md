# 지역 계획과 제어 구현 및 검증

## A. Local costmap

1. robot-centered window metadata 작성
2. LiDAR point marking
3. ray clearing
4. observation timestamp와 decay
5. footprint/inflation 적용

## B. Pure Pursuit baseline

1. nearest path segment
2. lookahead point
3. curvature와 angular velocity
4. goal 근처 감속과 정지

## C. DWA

1. dynamic window 계산
2. 후보 속도 생성
3. trajectory rollout
4. collision/admissibility 판정
5. cost별 단독 실험
6. weighted total cost
7. no-valid-candidate 처리

## D. Motion command

1. linear/angular saturation
2. acceleration limit
3. inverse kinematics
4. wheel-speed saturation 후 실제 `v`, `omega` 재계산

## 검증 시나리오

- 직선 경로
- 90도 회전
- 좁은 통로
- 정적 장애물
- 이동 후 사라지는 장애물
- U자 local minimum
- 모든 후보가 차단됨
- goal 근처 overshoot

## 지표

- cross-track error
- minimum clearance
- command smoothness
- stop distance
- oscillation count
- planning execution time
