# 공통 수학 구현 및 검증

## 구현 순서

1. `wrapAngle`을 MATLAB 함수로 작성한다.
2. pose를 3×3 transform으로 바꾸는 함수를 작성한다.
3. transform을 pose로 복원한다.
4. pose 합성과 상대 pose 계산을 구현한다.
5. base frame LiDAR 점을 map frame으로 변환한다.
6. timestamp age와 valid를 검사한다.
7. Simulink의 서로 다른 sample time 사이에서 데이터가 유지되는 예제를 만든다.

## 예정 파일

```text
src/+amr/+common/wrapAngle.m
src/+amr/+common/poseToTransform.m
src/+amr/+common/transformToPose.m
src/+amr/+common/composePose.m
src/+amr/+common/relativePose.m
src/+amr/+common/isFreshData.m
tests/unit/verify_common_math.m
models/prototypes/amr_timing_prototype.slx
```

## 필수 수치 검증

- `0`, `pi`, `-pi`, `3*pi`, `-3*pi` 각도
- identity transform
- 순수 평행이동
- 순수 회전
- 회전 후 평행이동 순서
- transform과 inverse의 곱
- 잘못된 회전행렬 입력
- timestamp 경계값

## 통과 기준

- transform 왕복 오차가 정한 tolerance 이내다.
- 각도 차이 계산이 `pi` 경계에서 연속적이다.
- 오래된 데이터가 정확히 invalid 처리된다.
