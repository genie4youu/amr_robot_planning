# 검증 전략과 성능 지표 이론

## 검증 계층

1. 수식 손계산
2. 순수 MATLAB 함수 unit verification
3. subsystem prototype 비교
4. 통합 scenario verification
5. 반복 random simulation
6. 이전 baseline과 regression 비교

## 입력 분류

- nominal
- boundary
- invalid
- noisy
- delayed
- missing
- contradictory

## 지표

### Modeling

- 해석해와 수치해 차이
- command tracking error
- saturation/acceleration limit 준수

### Mapping/SLAM

- occupied/free confusion matrix
- map IoU
- trajectory RMSE
- loop closure 전후 residual
- 잘못된 loop closure 수

### Localization

- position/heading RMSE
- distance-normalized drift
- convergence time
- failure/recovery rate

### Navigation

- path length
- minimum clearance
- cross-track error
- planning time
- command oscillation
- goal success rate

### Safety/Mission

- collision count
- hazard 감지 후 정지 시간
- false stop count
- recovery count
- mission completion time
- abort reason

## 허용 기준 설정

상용 수치를 임의로 복사하지 않는다. 작은 이상적 예제에서는 수학적 오차를 기준으로 하고, noise가 있는 통합 실험에서는 baseline 분포와 프로젝트 요구를 근거로 허용 범위를 정한다.
