# 가상 센서 구현 및 검증

## 구현 순서

1. 가장 단순한 벽 하나짜리 binary reference map을 만든다.
2. noise가 없는 단일 ray 결과를 검증한다.
3. 여러 각도의 scan을 생성한다.
4. lidar mounting transform을 적용한다.
5. encoder와 IMU ideal measurement를 만든다.
6. quantization, noise, bias를 각각 독립적으로 추가한다.
7. dropout과 delay queue를 추가한다.
8. prototype 모델에 센서 sample time을 분리한다.


## 검증 시나리오

- 벽에 수직인 빔
- 대각선 빔
- 최대 거리 안에 장애물 없음
- map 밖으로 나가는 빔
- lidar가 base 중심에서 offset됨
- encoder 한 pulse 미만 이동
- 고정 IMU bias
- 연속 dropout

## 성능 기록

LiDAR 빔 수와 지도 크기에 따른 실행 시간을 기록하되, 정확한 구현이 먼저다.
