# 전역 계획 구현 및 검증

## 구현 순서

1. occupancy probability를 planning cost로 변환한다.
2. obstacle distance와 inflation cost를 계산한다.
3. 4-neighbor A*를 작은 grid에 구현한다.
4. 8-neighbor와 diagonal corner rule을 추가한다.
5. path를 world pose로 변환한다.
6. collinear point 제거와 line-of-sight shortcut을 추가한다.
7. robot footprint 또는 inflated map으로 path를 재검증한다.
8. goal이 occupied일 때 허용 반경 내 대체 goal 정책을 검토한다.

## 검증 지도

- 빈 grid
- 하나의 벽과 한 개 통로
- U자 장애물
- 시작점 또는 목표점 occupied
- 경로 없음
- 두 개의 같은 비용 경로
- 좁아서 로봇이 통과할 수 없는 통로

## 지표

- path length
- minimum clearance
- expanded node count
- execution time
- 후처리 전후 waypoint 수
