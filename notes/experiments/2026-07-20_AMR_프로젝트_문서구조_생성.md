# AMR 프로젝트 문서 구조 생성

작성일: 2026-07-20

관련 프롬프트: [[2026-07-20_AMR_대형프로젝트_구조화]]

## 목적

MATLAB, Simulink, Stateflow만 사용하는 실내 배송 AMR 장기 프로젝트를 단계별로 학습·구현·검증할 수 있는 문서와 폴더 구조로 만든다.

## 적용한 구조

- 프로젝트 루트: `projects/indoor_delivery_amr/`
- 학습 순서: `stages/00`~`stages/13`
- 실제 MATLAB 함수: `src/+amr/`
- 모델: `models/examples/`, `models/mission_supervisor/`, `models/integrated_system/`
- 데이터: `data/maps/`, `data/scenarios/`, `data/expected/`
- 검증: `tests/unit/`, `tests/scenarios/`
- 결과: `results/`
- 공개 출처: `references/공개_출처.md`

## 주요 설계 결정

1. 학습 단계와 실제 코드를 분리했다.
2. mapping, localization, SLAM을 독립 단계로 만들었다.
3. Pure Pursuit는 기준 제어기, DWA는 최종 지역 계획기로 정리했다.
4. Stateflow는 임무와 복구를 담당하고 수치 알고리즘은 MATLAB/Simulink에 둔다.
5. safety monitor를 최종 속도 명령 앞의 독립 gate로 뒀다.
6. Simulink Test 없이 MATLAB `assert`와 `Simulink.SimulationInput`을 사용한다.
