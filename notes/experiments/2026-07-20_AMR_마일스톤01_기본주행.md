# AMR 마일스톤 01 — Stateflow 기본 주행

- 날짜: 2026-07-20
- 결과: PASS
- 프로젝트: [[실내 배송 AMR 프로젝트]]

## 목적

ROS/Robotics 관련 유료 Toolbox 없이 MATLAB, Simulink, Stateflow만으로 상위 임무 제어기부터 차동구동 플랜트와 결과 검증까지 이어지는 최소 실행 기준선을 만든다.

## 구현

- Stateflow: 초기화, 직진 1, 좌회전, 직진 2, 정지
- Simulink: 차체 속도에서 좌·우 바퀴 속도 계산, 이산 자세 적분
- MATLAB: 파라미터, 차동구동 순·역기구학, 독립 검증, 실행 및 plotting

## 실행

```matlab
cd('<작업공간>/projects/indoor_delivery_amr')
addpath('scripts','src','tests/unit')
verify_differential_drive
milestone01Results = run_amr_milestone01();
```

이 결과는 자율주행 완성이 아니라 개발 파이프라인의 수직 절편이다. 현재 이동은 시간 기반 open-loop이므로 센서 오차나 외란을 보상하지 못한다. 다음 마일스톤에서는 목표 pose와 현재 pose를 이용하는 폐루프 waypoint 추종기를 추가한다.
