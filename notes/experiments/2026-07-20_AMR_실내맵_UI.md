# AMR 실내 맵 애니메이션 UI

- 날짜: 2026-07-20
- 결과: PASS
- 선행 실험: [[2026-07-20_AMR_마일스톤01_기본주행]]

## 목적

정적 궤적 그림만 보는 대신 Simulink 결과의 로봇 자세를 실내 지도 위에서 시간에 따라 재생한다.

## 구현 기능

- 미터 단위 실내 floor plan, 벽, 장애물, 시작점, 목표점
- 방향이 있는 로봇 차체와 좌·우 바퀴
- 현재 위치까지의 이동 흔적
- Stateflow 상태, 시간, pose, 선속도, 각속도 표시
- 재생, 일시정지, 처음으로, 시간 탐색, 0.25~4배속

## 실행

```matlab
cd('<작업공간>/projects/indoor_delivery_amr')
addpath('scripts','src')
amrMapApp = launch_amr_map_ui();
```

## 검증

- 네 개 UI 소스 파일 MATLAB Code Analyzer 경고 없음
- 자동 재생 중 시간이 증가하는지 확인
- pause, 6초 seek, UI snapshot, reset, play 동작 확인
- 6초 표시: 상태 `좌회전`, pose `(2.000 m, 0.000 m, 45.0 deg)`

캡처: `projects/indoor_delivery_amr/results/2026-07-20_milestone01_map_ui.png`

현재는 solver 실행이 끝난 후 로그를 UI에서 재생한다. 이후 센서와 planner를 추가하면 지도상 장애물·계획 경로·센서 ray도 같은 UI에 겹쳐 표시한다.
