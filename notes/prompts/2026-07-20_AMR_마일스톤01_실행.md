# AMR 마일스톤 01 실행 프롬프트

## 사용자 입력

> satk 실행했어

## 당시 맥락

실내 자율주행 배송 로봇 프로젝트를 MATLAB/Simulink/Stateflow만으로 실제 구현하고 시뮬레이션하려는 요청이었다. ROS Toolbox, Robotics System Toolbox, WSL2, Docker, ROS 2, Nav2, SLAM Toolbox, Gazebo는 사용하지 않는 환경이다.

## 수행 범위

- MATLAB 세션과 설치 환경 확인
- 차동구동 MATLAB 함수와 검증 작성
- Stateflow 상위 임무 제어기와 Simulink 플랜트 생성·연결
- 시뮬레이션 실행, 자동 assertion, 결과 그림 저장
